# Native Codex account pool

Native OpenClaw workers do not execute the legacy `codex_local` adapter's account switcher. They receive credentials from OpenClaw's auth store. A single-profile auth order therefore strands other accounts even when `codex-auth list` reports available quota.

Run `node scripts/native-codex-accounts.mjs --refresh` to inspect the proposed allocation, then add `--apply --reload` to synchronize it and refresh the running gateway auth snapshot. Disk updates alone can leave the gateway using old credentials. Reload uses the selected package’s public `plugin-sdk/gateway-runtime` SDK with a 120-second RPC deadline and explicit `operator.admin` scope. Durable reload debt clears only after `{ ok: true, warningCount }` with a nonnegative safe integer warning count; rejected, timed out, or malformed responses retain the debt for an unchanged retry. There is no CLI reload fallback. The script supports codex-auth registry schema 4 and the public OpenClaw `plugin-sdk/provider-auth` SDK. It reads `OPENCLAW_STATE_DIR`, `OPENCLAW_CONFIG_PATH`, `CODEX_HOME`, and optionally `OPENCLAW_CODEX_ACCOUNTS_DIR`. Nonstandard installations can set `OPENCLAW_COMMAND`, `OPENCLAW_PACKAGE_ROOT`, or `CODEX_AUTH_COMMAND`.

The bridge imports one profile per user/workspace pair, preserves newer OpenClaw refreshes and native failure/cooldown state, and stores credentials through the shared auth owner's transaction. Agent stores receive explicit fallback orders referencing those shared credentials. It manages OpenAI-primary agents from the configured entries. Other provider orders remain intact. It does not switch the global Codex CLI login.

New worker sessions are distributed proportionally to the minimum remaining percentage across the short and weekly windows. Exhausted accounts sort last. Stale observations (over ten minutes) and reset windows are eligible for another native attempt. Every order retains all accounts so native cooldown and retry logic can recover. This uses percentages, not absolute plan capacity; Business and Plus percentages do not represent equal token budgets. Existing session pins and in-flight runs retain their auth binding until native retry or a new session.

For ongoing operation, schedule a single systemd oneshot invocation with `--refresh --apply --reload` every five minutes. Give it the same user, PATH, and state directory as the gateway and a five-minute timeout. A timer does not overlap its own service. Set `UMask=0077` and keep output private: it contains account identifiers but never tokens. A failed credential/registry validation or auth-store update returns nonzero. The command never purchases credits, consumes reset credits, resumes boards, or delivers messages.

Disable the timer to stop reconciliation. Before restoring an operator-specific order, disable reconciliation; otherwise the next pass reinstates the pool. Imported profiles are namespaced `openai:codex-auth:` and can be removed using OpenClaw's supported auth commands after removing their order references. Existing credentials are retained.

Validation: `node --test scripts/native-codex-accounts.test.mjs`. For a live check, resolve the effective native auth order for each worker and run isolated, non-delivering canary sessions, checking the runtime's recorded profile identity for each successful turn.
